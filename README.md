# 《三國志姜維傳》小說版

## 前言

《三國志姜維傳》是由臺灣創作者 ratchet 以《三國志曹操傳》為基礎製作的同人戰棋遊戲。作品以蜀漢後期名將姜維為主角，描寫諸葛亮北伐、蜀漢後期政局、魏滅蜀之戰，以及姜維在歷史與理想之間的選擇。

原作參考大量魏晉史料與現代研究，同時加入虛構人物及架空劇情。故事不只描寫戰場勝負，也觸及蜀漢內部不同族群與政治勢力的矛盾，並進一步探討人性、正統、國家認同，以及掌握公權力者應如何使用權力等議題。

本小說化改寫已取得原作者 ratchet 同意，以原作遊戲劇本為基礎，保留人物性格、主要事件，以及所採用路線中的原始角色台詞；另補充場景、動作、戰陣、心理活動與歷史背景，使遊戲劇情成為可以獨立閱讀的繁體中文長篇小說。

小說採用「三國演義式章回敘事」結合現代輕小說節奏。這不是原作的替代品，也不是新的官方續作。若希望體驗戰棋玩法、分支選擇、人物培養與完整遊戲演出，仍建議親自遊玩《三國志姜維傳》。

《三國志姜維傳》的原始劇情、人物與相關設定之權利，均歸原作者及相關權利人所有。

關於原作的基本介紹，可參考[維基百科：三國志姜維傳](https://zh.wikipedia.org/zh-tw/三國志姜維傳)。

## 閱讀路線

原作前半段為共通劇情。魏國大舉伐蜀後，故事因姜維是否派兵防守陰平而分成兩條主要路線：

- **共通線**：姜維投蜀、諸葛亮北伐、蜀漢後期政局、姜維歷次北伐，以及魏國伐蜀前期。
- **真結局線（幻想路線）**：姜維派兵防守陰平，成功識破鄧艾的奇襲，故事由此進入大規模架空歷史。
- **史實線（歷史路線）**：姜維不派兵防守陰平，鄧艾成功偷渡陰平，故事進入蜀漢滅亡與姜維復國失敗的歷史結局。

目前第一回至第五十七回已完成共通線及真結局線。史實線尚待小說化。

> 以下目錄包含路線分歧與章回標題，可能透露後續劇情。
